| How is the JSON-LD made safe in a script element? | Three replaces: `<`, `>`, `&` become the lowercase escapes `<`, `>`, `&` | `json_script` | AC10 wording; json_script adds an id and a wrapper and writes uppercase hex | build |
| Where is the text marked safe? | `mark_safe` in the view, on text the service already escaped | `\|safe` in the template | The escaping and the trust sit in two adjacent places, the service and the view | build |
| Where does the block live in base.html? | Inside the `{% if seo %}` part | Outside it | Only pages that pass `seo` can get the block | build |
