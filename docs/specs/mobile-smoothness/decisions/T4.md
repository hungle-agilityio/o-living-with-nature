# Decisions during build: T4 (#144)

| Question | Chosen | Rejected | Why | From |
|---|---|---|---|---|
| What sends the hero loop idle and wakes it | One source: the hero's IntersectionObserver (`seen`). At the end of `tick()`, once the intro is over and the observer last said "not near", the frame is cancelled and the loop is idle; the observer's "near" wakes it | Idle on `tick()`'s own `onScreen` measure | The two can disagree at the edge (a hero whose bottom sits exactly at the top of the screen is "intersecting" for the observer, not for `tick()`): the loop then idled and no later observer callback ever woke it. With the observer as the only judge, a wake-up callback always follows an idle | build (code review, rounds 1 and 2) |
| When the hero wakes | 10% of the screen height before it reaches the screen (`rootMargin: "10% 0px"`, as for the photos) | Wake only once it is on screen | Without a margin the first visible frame shows the last picture drawn and a paused video | build (code review, round 2) |
| Size of the frame after an idle | Measure on wake only when the frame size changed | Always measure on wake; never measure | The resize handler skips measuring while idle (AC2), so a size change is caught on return; a full measure resizes the canvas and reads pixels back, needless when nothing changed | build (code review, round 2) |
| The late-font handler while idle | Kept as on `main`: it may measure once, off screen, when the font arrives within the 3 s wait | Skip it while idle | The existing test `test_hero_font_wait.py::test_late_font_remeasures_the_running_intro_before_go` pins that line, and the issue changes no existing test; it runs at most once per page load, never on scroll | build (code review, round 1) |
| Room in `hero.js` (13,978 bytes, limit 14,000) | Shorten the header and other comments (now 13,995 bytes) | Raise the limit | The limit is pinned by existing tests (owner's Decisions) | owner |
| Photos near the screen without IntersectionObserver or under reduced motion | Nothing changes: `reveal.js` has already returned, so there is no class `motion` and no zoom | A fallback that sets `is-near` | As the issue says | owner |
