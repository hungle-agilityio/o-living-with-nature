# Decisions during build: T5 (#120)

| Question | Chosen | Rejected | Why | From |
|---|---|---|---|---|
| Label suffix on the change page | `EnquiryStatusForm` sets `label_suffix=""`, so the read-only rows and the Status label have no colon | Keeping Django's "Received:" | The row-order test looks for "Received " and the design shows no colons | build |
| Where the change page title is set | `render_change_form` overrides `title`, `subtitle` and `show_save_and_continue` in the context | `change_view(extra_context=...)` | `_changeform_view` builds `title` and `subtitle` itself after `extra_context`, so only `render_change_form` has the last word | build |
| How the empty state replaces the blocks | The template overrides `block content` and shows two paragraphs when `cl.full_result_count == 0`, else `block.super` | Hiding each block (actions, table, paginator, filter) separately | One condition, and nothing of Django's list can slip back in | build |
| Actions bar and scroll box | The actions bar is drawn outside `<div class="enq-scroll">`; only `{% result_list cl %}` is inside | Wrapping the actions too | The bar must not scroll sideways with the table | build |
| `rows_of` of the test when there is no table | It returns `[]` when Django draws no `result_list` (AC4: no table for zero rows) | Rendering an empty table | Django draws none for zero rows | build |
| Browser axis | Not run: `/owner/` needs a login the browser check cannot do; the admin screens are checked by HTML assertions and the owner looks on the local preview | A browser step | The issue's own Decisions | owner |
| `get()` helper of the test | Typed `**extra: Any` so `mypy --strict` passes | Leaving it untyped | Same checks, no test weakened | build |
| Who may run the actions | "Mark as replied" and "Mark as new" need the change permission (`permissions=["change"]`) | Any staff user who can view the list | A view-only account must not change a status; found in review | build |
| When the cleanup runs | `delete_expired` runs only after the view permission check passes; others get 403 and nothing is deleted | Deleting before the check | A refused request should change no data; found in review | build |
| Status label in the list | `get_status_display()` | `Status(obj.status).label` | An unexpected stored value no longer breaks the whole list; found in review | build |
| Message spacing | `.enq-msg` gets `white-space: pre-wrap` | Default white-space | The issue asks for white-space kept | build |
