# Ở — Living with Nature

Bilingual (Vietnamese and English) website of a rental garden house in Hòa Xuân, Đà Nẵng. Django 5, Python 3.11.

```
uv sync
uv run python manage.py runserver
uv run pytest -q
```

How the project is built and worked on: [`CLAUDE.md`](CLAUDE.md) and [`.claude/`](.claude/).
